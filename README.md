## 🌐 Tentang OCTO Platform

**OCTO** adalah platform teknologi bisnis modern yang menjembatani interaksi fisik di dunia nyata (*offline touchpoints*) dengan kekuatan komputasi dan analitik digital (*online intelligence*).

Banyak bisnis lokal dan jaringan cabang menghadapi hambatan besar di meja kasir:
1. Pelanggan yang puas jarang menyempatkan diri menulis ulasan di Google Maps karena proses pencarian manual yang lambat dan merepotkan.
2. Bisnis kehilangan data analitik berharga mengenai sentimen dan kepuasan pengunjung harian.
3. Program loyalitas tradisional berbasis kartu stempel kertas mudah hilang dan tidak terhubung ke basis data pelanggan.

OCTO hadir menyatukan seluruh mata rantai tersebut ke dalam satu ekosistem yang terhubung, konsisten, dan terukur.

## 💎 Prinsip & Filosofi Utama

1. **Proof over Hype**:  
   OCTO tidak menjual klaim muluk atau manipulasi algoritma. Kami memangkas friksi teknis agar kepuasan pelanggan asli dapat terkonversi menjadi ulasan organik nyata di Google Review.
2. **Zero App Friction**:  
   Pelanggan tidak dipaksa mengunduh aplikasi tambahan (*no app install required*). Seluruh interaksi memanfaatkan kapabilitas bawaan smartphone modern (NFC native dan kamera QR).
3. **Hardware-Software Synergy**:  
   Perangkat fisik akrilik berstandar industri berpadu harmonis dengan arsitektur cloud, pengalihan tautan dinamis (*single source of truth*), dan portal analitik bisnis.
4. **Data Governance & Privacy-First**:  
   Sepenuhnya mematuhi prinsip Undang-Undang Pelindungan Data Pribadi (UU PDP). Privasi pelanggan dihormati dengan transparansi preferensi cookie dan enkripsi data sesi.

### 1. OCTO Tap (Tersedia / Live)
Perangkat fisik interaktif stand akrilik untuk meja kasir dan meja tamu.
- **Standar Fisik**: Format persegi 10×10 cm (100×100 mm), akrilik bening 3mm tahan benturan, air, dan goresan meja restoran.
- **Dual-Technology**:
  - Chip NFC **NTAG213** (13.56 MHz, Standar ISO/IEC 14443 Type A) untuk sentuhan 1 detik langsung membuka form Google Review.
  - **High-Contrast QR Code** terkalibrasi untuk kamera seluruh ponsel.
- **4 Pilihan Desain Resmi**:
  - *OCTO Signature* (Navy `#0B132B` & Cyan `#00AFC4`)
  - *Frosted Glass* (Glassmorphism akrilik bening elegan)
  - *Google White* (Minimalis bersih dengan 4-color Google accent)
  - *Black & Gold* (Obsidian mewah & aksen emas untuk fine dining/butik)
- **Zero Maintenance**: Bekerja pasif selamanya tanpa baterai atau kabel pengisi daya.

### 2. OCTO Insights (Akses Terbatas / Closed Beta)
Pusat analitik ulasan dan kecerdasan reputasi bisnis.
- Agregasi sentimen pelanggan secara otomatis dari berbagai kanal.
- Pendeteksi anomali rating dan peringatan dini keluhan pelanggan.
- Laporan benchmark reputasi kompetitor di wilayah sekitar gerai.

### 3. OCTO Loyalty (Dalam Pengembangan)
Sistem retensi dan stempel loyalitas digital tanpa friksi.
- Reward stempel digital berbasis sentuhan NFC / scan kasir.
- Pelacakan pelanggan setia (*returning customers*) tanpa kartu plastik fisik.
- Sistem voucher dan kupon promosi otomatis saat pelanggan berulang tahun.

### 4. OCTO Business (Segera Hadir)
Pusat komando terpusat bagi pemilik jaringan bisnis multi-cabang (*franchise & chain stores*).
- Manajemen distribusi ratusan perangkat OCTO Tap per cabang.
- Pengaturan izin peran (*Role-Based Access Control* / RBAC).
- Laporan komparasi performa antar-cabang secara *real-time*.

### 5. OCTO CRM (Terintegrasi)
Manajemen kontak, pendaftaran demo, dan pipeline prospek kemitraan yang terhubung langsung ke sistem internal OCTO.

## 🏢 Solusi Industri

OCTO dirancang dengan modul penerapan spesifik sesuai karakteristik industri:
- **Retail & Toko Modern**: Optimalisasi interaksi kasir kasual, toko busana, elektronik, dan minimarket.
- **Kafe & Restoran (F&B)**: Format stand meja yang tahan tumpahan minuman, minyak, dan aktivitas padat.
- **Klinik Kecantikan & Spa**: Estetika premium (Frosted Glass / Gold) untuk ruang tunggu perawatan.
- **Kesehatan & Faskes**: Membantu klinik dokter dan apotek mengumpulkan testimoni kenyamanan layanan.

## 🚀 Panduan Memulai

### Prasyarat
- **Node.js**: Versi `20.x` atau lebih baru
- **Package Manager**: `npm` (disarankan), `pnpm`, atau `yarn`

### 1. Instalasi Dependensi
```bash
npm install
```

### 2. Menjalankan Server Pengembangan (Dev)
```bash
npm run dev
```
Akses aplikasi melalui browser di [http://localhost:3000](http://localhost:3000).

### 3. Build untuk Produksi
```bash
npm run build
```

### 4. Menjalankan Server Produksi
```bash
npm start
```

### 5. Pengecekan Linting
```bash
npm run lint
```
